# Ảnh màn hình sản phẩm (PNG rời)

Toàn bộ ảnh trong thư mục này được **xuất ra từ hai file hướng dẫn sử dụng** trong `docs/`, để xem trực tiếp trên GitHub mà không phải tải `.docx`/`.pdf` về giải nén.

| Thư mục | Số ảnh | Nguồn | Nội dung |
|---|---|---|---|
| [`web-admin/`](web-admin) | 19 | `docs/huong-dan-su-dung-web-admin.docx` | Đăng nhập, dashboard, kho tri thức, văn bản pháp quy, danh mục HIS, người dùng, vai trò & quyền, nhật ký kiểm toán, cấu hình AI / robot / hệ thống |
| [`extension-chrome/`](extension-chrome) | 23 | `docs/huong-dan-su-dung-extension-chrome.docx` | Cài đặt extension vào Chrome và thao tác thật trên màn hình HIS |

Tên file theo dạng `<số thứ tự>-<mục trong tài liệu>.png`, giữ đúng thứ tự xuất hiện trong hướng dẫn - đọc lần lượt là đi đúng luồng thao tác.

Muốn xuất lại sau khi cập nhật tài liệu: ảnh nằm ở `word/media/` bên trong file `.docx` (bản chất là file ZIP), giải nén ra là được.
